# Flap track research and design decisions

Reviewed November 27, 2026, Bangkok time. The following sources informed the submitted mechanism.

| Evidence | Application to HexPit |
| --- | --- |
| *Flap Track - BNB Hack.pdf*, pp. 3–6 (sponsor brief) | The entry requires a factory, a complete public BSC testnet token launch and a custom UI. A Vault is optional. Judges request code, testnet evidence and a short explanation. |
| *Build Your Innovative Launch Mechanism on Flap Pool Launch Protocol*, workshop PDF and PPTX with speaker notes, slides 4–14 | Use the Pool Launch Portal. Allocate all supply at launch, account for LP burn and provide buyer claims. The workshop's native-asset MintLauncher is an example; HexPit uses the approved faucet ERC-20. The workshop ties mainnet assistance to a zero developer launch commission. The roadmap mentions future pool features; this entry uses the demonstrated V2 integration. The separately supplied PDF and exported copy matched byte for byte. |
| Event Telegram export, November 25–26 | Organizer guidance pointed to the faucet USD, permissionless test mint and upgraded testnet factory helper. Participant addresses and example transfers were excluded from team evidence. On-chain calls verified the token and helper independently. |
| [HackQuest event and Flap challenge](https://www.hackquest.io/hackathons/BNB-Bangkok) | Submissions close November 27 at 09:00 Bangkok, 02:00 UTC. A registered, approved participant confirms attendance, selects the team project and sponsor challenge, submits, and checks for confirmation. |
| [Pool Launch mechanics](https://docs.flap.sh/en/flap/v2/developers/pool-launch/basic-and-mechanism) and [launch guide](https://docs.flap.sh/en/flap/v2/developers/pool-launch/launch-tokens) | Quote liquidity is raised by the Launcher. Both liquidity floors scale with the share of supply put into the pool. With a 50% pool share and 100-bps test multiplier, the documented nominal creation and graduation floors are 15 and 30 test USD at the 1 USD test quote. The demo raises 60. Mainnet permissioning is separate. |
| [Build guide](https://docs.flap.sh/en/flap/v2/developers/pool-launch/build-on-pool-launch) and [deployed addresses](https://docs.flap.sh/en/flap/v2/developers/deployed-contract-addresses) | Use chain 97, an enabled quote asset, exact ERC-20 approval, zero native payment on token launch, salt reservation from the launcher, and an explicit strategy that pulls the full player allocation. The testnet salt-lock fee read at launch was 0.005 tBNB. |
| [Indexer guide](https://docs.flap.sh/en/flap/v2/developers/pool-launch/build-an-indexer) | Follow Portal launcher provenance, issuance, token and pool. The judge site supplements those receipts with PackOpened events and checks the launcher belongs to the team factory before preparing writes. |
| [Contract example at the pinned commit](https://github.com/flap-sh/FlapPoolLaunchVaultExample/tree/29334f689774f6b3a39720b3fc802ab0d6a61718) | Reviewed MintLauncher, its factory and fork tests. Adopted LauncherFactoryBase, a Guardian-controlled beacon, LauncherBase and the explicit distribution callback. CrowdLauncher and StakeMineVault solve different reward problems. |
| [Workshop launcher template](https://github.com/flap-sh/flap-vault-component-template/tree/3a7fa025f7a73dd6b6ff4eecce4e990bf33e1a06/examples/launcher-runtime) | Project-operated one-off launchers use the detail-only interface. Its generic action bridge supports zero-argument calls. The standalone wallet page supports ERC-20 approval and amount-bound minting. The three Workbench input files are separately packaged. |
| [Flap faucet](https://abc.flap.sh/faucet?lang=en), [BNB gas faucet guidance](https://docs.bnbchain.org/bnb-smart-chain/developers/faucet/), [testnet helper](https://testnet.bscscan.com/address/0x77779969a11eff7582f3bCf48135A846A3457777#code) | The USD faucet token reports symbol USD and 18 decimals. The Portal reported an enabled quote and a 1e18 reference price. The helper overload used by the entry is whitelist(address,uint16). Native test BNB pays only protocol setup and gas. |
| Existing DEXPit mint pilot and canonical catalog | Preserved five-card packs, 117 card definitions, rarity bands, separate card ownership and buyer GAME entitlements. The previous private demonstration used a local-only market. The public entry contains its own BSC testnet contracts and evidence. |
